# 2048-Game
Built a 2048 game in Java from scratch using object-oriented programming principles. Includes custom movement and merging logic, random tile spawning, game-state validation, and a clean separation of responsibilities across classes.


## What I Learned
 
- 2D array manipulation
- Object-oriented design in Java
- Game state management
- Algorithm design for tile movement and merging
- User input handling
- Debugging and testing game logic
